•	Use only the D icon (without wordmark) for app icons, favicons, and small spaces
•	The white version of the full logo can be used on dark navy backgrounds

Logo Don'ts
•	Never stretch, skew, or distort the logo proportions
•	Never change the logo colors to anything outside the brand palette
•	Never place the logo on busy photographic backgrounds without a white/dark solid overlay
•	Never add drop shadows, outlines, or effects to the logo
•	Never use the wordmark without the icon in marketing materials
•	Never recreate the logo — always use the approved PNG/SVG files

1. Concept Overview


What is the Doctor's Public Page?
Every doctor who subscribes to Doctylia automatically gets their own professional public-facing website — their personal digital clinic. This page is fully dynamic, managed entirely from their admin panel. Patients can visit it, learn about the doctor, view services/packages, book appointments, and even join an online consultation — all without any technical setup by the doctor.

The custom domain request flow: Doctor fills a form in their admin panel → Doctylia team reviews within 24 hours → Payment of ₹4,999 collected via Razorpay → Doctylia team configures DNS/SSL → Doctor verifies → Live within 48–72 hours.

1.2 Key Principle — Doctor Owns Everything
•	The doctor controls 100% of the content — no Doctylia editorial involvement
•	All content is managed from the doctor's admin panel in real-time
•	Changes go live instantly — no waiting for approval
•	The page is fully mobile responsive and fast-loading

•	The page works 24/7 even when the doctor is not logged in

3. Custom Domain — Full Feature Specification

15.	Doctor clicks 'Verify DNS' in admin panel — system auto-verifies
16.	Doctylia team configures SSL certificate (Let's Encrypt / Cloudflare)

◆ LEFT PANEL — SECTION ACCORDIONS
Each accordion item has: section name, ON/OFF toggle, expand arrow.
When expanded: shows form fields for that section.

1. HERO (always on, no toggle):
   - Profile photo upload (drag-drop + click, circular preview, 400x400 min)
   - Display name field
   - Specialization dropdown (20+ options)
   - Qualification text (e.g., MBBS, MD Cardiology)
   - Years of experience number input
   - Hospital/Clinic affiliations (add multiple)
   - Languages spoken (multi-select chips)
   - Enable Online Consultation toggle (shows/hides Online CTA button)

2. QUICK STATS (toggle):
   4 rows: [Label input] [Number input] for each stat

3. ABOUT (toggle):
   - Rich text editor for bio
   - Education entries (add/remove): Degree, Year, Institution
   - Specialization tags (comma-separated or chip input)
   - Memberships (add/remove text entries)
   - Awards (add/remove: Award name, Year)
   - NMC Registration Number field

4. SERVICES (toggle):
   - Service list (drag-drop to reorder)
   - Each service row: Name | Price ₹ | Type (Clinic/Online/Both) | Duration | Active toggle
   - '+ Add Service' button opens inline form
   - Edit/Delete per service

5. PACKAGES (toggle, off by default):
   - Package list with cards
   - Each: Name, Tagline, What's Included (bullet editor), Duration, Price,
     Original Price (optional), Slots Available (optional), Most Popular toggle
   - '+ Add Package' button

6. GALLERY (toggle, off by default):
   - Photo upload grid (up to 6 slots, shows placeholder boxes)
   - Click any slot to upload, drag to reorder
   - Caption input below each uploaded photo
   - Delete icon on each photo

7. ONLINE CONSULTATION (toggle, off by default):
   - Consultation fee ₹ input
   - Session duration dropdown (15/30/45/60 mins)
   - Available days (checkboxes Mon-Sun)
   - Start time + End time per day

8. BOOKING SETTINGS (always on):
   - Advance booking window dropdown (3/7/14/30 days)
   - Minimum notice period (1h/2h/4h/1 day)
   - Require payment toggle (Yes/No)
   - Deposit amount ₹ (shows only if payment required)
   - Auto-confirm bookings toggle
   - Max patients per slot (number input)
   - Buffer between appointments (0/5/10/15 mins)

9. REVIEWS (toggle):
   - Allow new reviews toggle
   - Reviews list: each with patient name, rating, date, text,
     'Pin to Top' and 'Hide' action buttons

10. BLOG: Read-only note 'Manage your blog posts in the Blog section →'
    with a link. Shows count of published posts.

11. CLINIC DETAILS (toggle):
    - Clinic name, full address (Street, Area, City, State, PIN)
    - Google Maps URL input + 'Preview Map' button
    - Working hours: per-day table with Open toggle + time range picker
    - Phone 1, Phone 2, WhatsApp number, Email
    - Parking info text, Landmark text

12. WEBSITE SETTINGS (gear icon, not a section toggle):
    - Page language dropdown
    - SEO: Page title, meta description, keywords
    - Color theme: 5 swatches to select
    - WhatsApp message pre-fill text
    - Social media links (4 inputs)
    - Google Analytics ID, Facebook Pixel ID
